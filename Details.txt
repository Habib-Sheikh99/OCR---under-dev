### OCR ###

  -> This model was created from scratch, by the help of Pytorch.
  
  
the dataframes used to train the model was :
1) EMNIST
2) RetinaNet Keras (For Number Plates)
3) ...


the Specification of the model is written below :
- Can detect Number plates by just seeing the picture of a car.
- If visible, The model can generate the Code written on the Number Plates of the vehicles.
- Can Recognize Text from raw or processed Documents.
- Can be used by buiseness to automate their recognition process.
- The Error rate will always be there, so the user knows when to trust the model and when not.
